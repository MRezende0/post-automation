# Voz do Cliente (Voice of Customer)

> Léxico real do ICP — as palavras que o cliente usa, não as nossas. É o que separa copy
> premium de copy genérica. Injetado no prompt como vocabulário preferencial.
> Regra de ouro: **escreva com as palavras deles, não com as suas.**

## Como abastecer (fontes reais — priorizar dados do próprio Pilar)

1. **Motivo de perda de lead** (campo existe no Pilar) — por que NÃO fecharam? São objeções literais.
2. **Tickets de suporte** — o que confunde/trava o usuário, nas palavras dele.
3. **Onboarding / churn** — por que entram e por que saem.
4. **Comentários e DMs** no Instagram (@pilar.software, @vrzengenharia).
5. **Reviews de concorrentes** (Sienge, Vobi) — reclamações = dores não atendidas.
6. **Entrevistas** com 3–5 donos reais (1h).

> ⚠️ Itens 1–3 estão no banco do Pilar (Supabase). Exportar e colar aqui (anonimizado).

## Termos a EVITAR (não são a linguagem dele)

- "Performance", "rentabilidade", "previsibilidade" → ele diz **lucro, sobrar, no vermelho, no escuro**.
- "Otimizar", "gestão eficiente", "solução integrada" → corporativês, não fala.
- "Obra", "canteiro" → fora do ICP (ele faz projeto, não obra).

## Equivalências (nosso termo → termo dele)

| Falamos | Ele fala |
|---|---|
| rentabilidade por projeto | "saber se esse projeto deu lucro" |
| fluxo de caixa | "quanto entra e quanto sai" |
| faturar por marco | "receber por etapa" |
| capacidade da equipe | "quem tá sobrecarregado" |
| margem | "o que sobra" |
