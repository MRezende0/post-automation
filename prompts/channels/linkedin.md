# Canal: LinkedIn

## Formato e limites

- **Post:** até 1300 caracteres no preview. Texto pode ir até 3000 mas só os primeiros 200 chars aparecem antes do "ver mais"
- **Hook nas 2 primeiras linhas.** Decide se o post é lido ou não.
- **Quebra de linha entre cada bloco de ideia.** LinkedIn premia respiro.
- **Emoji:** 0–2, sempre funcional (▪️, →). Nunca foguete, palma.
- **Hashtag:** 3 ao final, específicas. Sem #motivation #success.
- **CTA:** pergunta no final. LinkedIn premia comentário.

## Formatos suportados

- `text` — post de texto, opcional 1 imagem 1200×627
- `carousel` — PDF com 5–10 slides 1080×1080. Funciona muito bem em B2B.

## Estrutura recomendada por pilar

### Dor (formato preferido: text)
```
[Linha 1 — hook forte]
[Linha 2 — expande]

[2–3 parágrafos curtos detalhando]

[1 parágrafo de implicação]

[Pergunta de encerramento]

[3 hashtags]
```

### Dica (formato preferido: carousel PDF OU text com lista)
```
[Hook: promessa + contexto]

[2 linhas explicando o problema]

→ Dica 1: ação + por quê
→ Dica 2: ...
→ Dica 3: ...
→ Dica 4: ...
→ Dica 5: ...

[1 parágrafo de fechamento]

[Pergunta]
```

### Building (formato preferido: text)
Mais longo (800–1200 chars). Vulnerabilidade controlada. Número quando tiver. LinkedIn é o melhor lugar pra building in public B2B.

### Prova (formato preferido: text com 1 imagem)
Citação + contexto + resultado. Imagem pode ser screenshot autorizado.

## Diferença chave vs Instagram

| | Instagram | LinkedIn |
|---|---|---|
| Tamanho | 120–180 palavras | 200–250 palavras |
| Tom | mais leve | mais profissional |
| Emoji | só funcional, raro | 0–2 funcional |
| Pergunta final | retórica | convida resposta real |
| Vínculo com produto | sutil | pode ser mais direto |
