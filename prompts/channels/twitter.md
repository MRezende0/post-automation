# Canal: Twitter / X

## Formato e limites

- **Limite:** 280 caracteres por tweet. Post curto = 1 tweet; ideia que não cabe = **thread**.
- **Tom:** informal, direto, conversado. Menos "post de marca", mais "engenheiro falando com engenheiro".
- **Hook = primeiro tweet.** Tem que parar o scroll sozinho, sem depender do resto.
- **Sem floreio.** Frase seca. Uma ideia por tweet numa thread.
- **Emoji:** quase nunca. Hashtag: 0–1, só se agregar (X premia pouco hashtag).
- **CTA:** pergunta curta ou convite a responder. Engajamento em X = reply/retweet.

## Formatos suportados

- `single` — 1 tweet (≤280 chars). Default pra dor/prova curtas.
- `thread` — 2–6 tweets encadeados. Default pra dica (passo a passo) e building (narrativa).

## Estrutura recomendada por pilar

### Dor (formato preferido: single)
Um tweet que nomeia a dor com elemento concreto. Ex: "Rev04 publicada quando devia ser Rev06. Cliente achou em campo. Ninguém sabe quem mandou."

### Dica (formato preferido: thread)
```
Tweet 1: promessa curta ("3 jeitos de saber se o projeto deu lucro:")
Tweet 2–N: 1 dica por tweet, ação + por quê
Último: pergunta ou "qual desses tu já faz?"
```

### Building (formato preferido: thread)
Narrativa em 3–5 tweets. Número aberto quando tiver. Vulnerabilidade real, sem polimento.

### Prova (formato preferido: single)
Citação curta do cliente + resultado concreto num tweet.

## Diferença chave vs LinkedIn/Instagram

| | Instagram | LinkedIn | Twitter/X |
|---|---|---|---|
| Tamanho | 120–180 palavras | 200–250 palavras | 280 chars/tweet |
| Tom | leve | profissional | informal, cru |
| Estrutura | legenda + imagem | parágrafos espaçados | tweets curtos / thread |
| Hashtag | 4–7 | 3 | 0–1 |
| Imagem | central | opcional | opcional, secundária |
